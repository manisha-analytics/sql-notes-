# 📊 SQL Notes & Reference Guide

Welcome to the SQL learning session archive! This repository contains a complete roundup of essential SQL queries, advanced functions, and virtual tables.

---

## 🛠️ SQL Architecture Components

Here is the structured breakdown of core SQL components covered in this session:

* **DDL (Data Definition Language):** Used to define the database structure.
* **DML (Data Manipulation Language):** Used for managing data within objects.
* **DQL (Data Query Language):** Used to fetch data from the database.
* **DCL (Data Control Language):** Used for managing permissions and access.

---

## 📚 Topics Covered

### 1. Fundamentals & Core Operations
* **Database Operations:** `CREATE DATABASE`, `DROP DATABASE`, `USE`
* **Data Types & Table Basics:** `INT`, `VARCHAR`, Constraints (`NOT NULL`, `UNIQUE`)
* **Table Operations (DDL):** `CREATE TABLE`, `ALTER TABLE`, `DROP TABLE`
* **Data Operations (DML):** `INSERT`, `UPDATE`, `DELETE`, `TRUNCATE`

### 2. Querying & Data Retrieval (DQL)
* **Basic Querying:** `SELECT`, `WHERE` clause
* **Operators & Filters:** `BETWEEN`, `LIKE`, `IN`, `AND / OR`
* **Sorting:** `ORDER BY` (Ascending / Descending)
* **Aggregate Functions:** `SUM()`, `AVG()`, `COUNT()`, `MIN()`, `MAX()`

### 3. Advanced Concepts & Relationships
* **Table Relationships:** Primary Key & Foreign Key Relations
* **Advanced Querying:** `GROUP BY`, `HAVING` clause
* **Joins:** `INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`, `FULL JOIN`

### 4. Window Functions (Advanced Analytics) 🆕
* **Over Clause:** `OVER (PARTITION BY ... ORDER BY ...)`
* **Ranking Functions:** `ROW_NUMBER()`, `RANK()`, `DENSE_RANK()`
* **Value Functions:** `LAG()`, `LEAD()`

### 5. Database Views (Virtual Tables) 🆕
* **View Creation:** `CREATE VIEW view_name AS ...`
* **Querying Views:** Running standard `SELECT` on saved views to simplify complex joins.
* **Benefits:** Implements data security and reduces code redundancy.
